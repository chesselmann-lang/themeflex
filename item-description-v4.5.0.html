🗂️ Manifest-Based Demo System

v4.5 introduces a file-based demo discovery engine. Instead of registering every demo site in PHP code, ThemeFlex now scans demos/*/manifest.json at runtime and merges any discovered demos into the importer automatically.

Zero-Code Demo Additions Drop a new folder into demos/ with a manifest.json — the importer shows it immediately. No PHP, no re-deploy.
Smart Category Mapping Manifest tags are automatically mapped to the importer's 19 industry categories via a 40-entry keyword map. "hotel", "resort", "boutique" → Travel & Events.
Conflict-Free Merging Slugs already present in the hardcoded template database are skipped, so existing importable demos are never overwritten by manifest-only preview entries.
17+ New Demo Sites Bundled manifests include: Hotel / Luxury Resort, CV / Resume, Real Estate Portfolio, Restaurant, Agency, SaaS, Law Firm, Fitness Studio, Photography, Wedding Planner, Medical Practice, and more.

Each manifest.json specifies: id, name, description, skin, version, preview_url, required_plugins, pages, tags, and author. The importer renders manifest demos with a "Preview" badge and links directly to the live demo URL.

🤖 AI Site Chat — Built-In RAG Engine

ThemeFlex ships a fully integrated AI chat widget that can answer visitor questions using your actual site content — no external SaaS subscription required, no per-seat fees.

Multi-Provider Support Connect Anthropic Claude, OpenAI GPT-4o, or Google Gemini. Swap providers in WP Admin → ThemeFlex → AI Settings with a single API key field.
RAG — Retrieval-Augmented Generation TF-IDF indexer builds a JSON vector store from your pages and posts. The chat widget retrieves the most relevant passages before answering — grounded, accurate responses.
DSGVO Consent Gate The chat bubble only activates after the visitor accepts the "AI Functions" cookie category. Consent state is read from the themeflex_consent cookie — compliant by default.
Admin AI Panel Token usage log, indexer status display, manual re-index button, API key management with live validation. No third-party dashboard needed.
📋 Requirements for AI Chat: An API key from Anthropic, OpenAI, or Google AI Studio is required. The key is stored in your WP database and never transmitted to third parties. The AI Chat feature is entirely optional — ThemeFlex works without it.

🏭 Industry Setup Wizard & One-Click Demo Importer

Getting started has never been faster. The 3-step wizard detects your industry, recommends the right template, and imports it — complete with placeholder content at your chosen depth.

  • Step 1 — Industry Detection: Type a keyword (e.g. "dentist", "yoga studio", "craft brewery"). AI-assisted matching if an API key is configured; fast substring fallback otherwise.
  • Step 2 — Template Selection: Preview recommended templates with schema type, skin, and industry tags. 19 industries × 114 templates fully mapped.
  • Step 3 — One-Click Import: Creates WP pages as drafts, applies the recommended skin, sets the front page — in under 5 seconds.

Content depth selector: Import headlines only, short descriptions, or full content (H2s + body text + FAQ) — your choice per import.
