The essential companion plugin for the Starter Flavor WordPress theme.

== Description ==

**Starter Flavor Addons** supercharges the Starter Flavor theme with:

= 🎨 10+ Custom Elementor Widgets =
* **Portfolio Grid** – Filterable grid with masonry layout and hover effects
* **Team Members** – Card grid with social links and CPT integration
* **Testimonials Slider** – Star ratings, autoplay, multiple layouts
* **Pricing Table** – Feature checklist, featured badge, custom CTA
* **FAQ Accordion** – Schema.org markup, single/multiple open modes
* **Stats Counter** – Scroll-triggered count-up animation
* **Timeline** – Vertical/horizontal, scroll animation
* **Logo Carousel** – Infinite scroll, grayscale hover effect
* **Icon Box** – 5 card styles, 5 hover effects
* **Map Embed** – OpenStreetMap (no API key needed) or Google Maps

= 📦 5 Custom Post Types =
* Portfolio (with categories taxonomy + meta fields)
* Team Members (role, social links)
* Testimonials (author, rating, position)
* FAQ (question/answer with categories)
* Pricing Plans (price, period, features, CTA)

= 🚀 One-Click Demo Importer =
Import any of 20+ complete demo packs with:
- Full page content
- Customizer settings (colors, fonts, logo)
- Navigation menus
- Elementor templates
- Page assignments (homepage, blog)

= 20+ Demo Packs =
Corporate, Restaurant, Creative Agency, SaaS, Portfolio, Medical, Real Estate, Education, Blog, E-Commerce, Wedding, Photography, Fitness, Law Firm, Architecture, Nonprofit, Fashion, Travel, App Landing, Startup

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/starter-flavor-addons/`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to **Starter Flavor → Demo Importer** to import a demo

== Frequently Asked Questions ==

= Do I need the Starter Flavor theme? =
Yes, this plugin is designed to work with the Starter Flavor theme. It will show a notice if a different theme is active.

= Is Elementor required? =
Elementor is required only for the custom widgets. The demo importer, custom post types, and admin features work without Elementor.

= Are the demos included or downloaded? =
Demo content files are bundled with the plugin. No external downloads required.
