Free version of Starter Flavor — modern WordPress theme with 10 Elementor widgets, 3 skins, and 3 demos.

== Description ==

Starter Flavor Free is the free entry point to the Starter Flavor theme ecosystem.

Free version includes:
* 10 custom Elementor widgets
* 3 professional skins (Default, Corporate, Creative)
* 3 one-click demo sites
* WooCommerce compatible
* Dark mode support
* Responsive design
* WCAG 2.1 AA accessible

Upgrade to Pro (on ThemeForest) for:
* 80+ Elementor widgets
* 20 professional skins
* 27 one-click demos
* AI Content Assistant (OpenAI)
* WooCommerce Quick View, Wishlist, Sticky Cart
* Template Library (50+ sections)
* White-Label option
* Priority support

== Installation ==
1. Upload and activate the theme
2. Install Elementor (free)
3. Import a demo via Appearance → Demo Importer
