ThemeFlex Documentation

Welcome to the official documentation for ThemeFlex — the most complete WordPress theme ecosystem with 80+ Elementor widgets, 20 professional skins, and 15 one-click demos.

System Requirements

  • WordPress: 6.0 or higher
  • PHP: 8.0 or higher
  • Elementor: 3.0+ (free version — Pro not required)
  • ThemeFlex Addons: Companion plugin (included in download)
  • MySQL: 5.7+ or MariaDB 10.3+

Installation Steps

1

Upload the Theme

Go to WordPress Admin → Appearance → Themes → Add New → Upload Theme. Select themeflex.zip from your download and click Install Now, then Activate.

2

Install Required Plugins

After activation, a notice appears at the top of wp-admin. Click Install Elementor and Upload ThemeFlex Addons. Both are required for full functionality.

3

Import a Demo (Optional)

Go to Appearance → Theme Setup → Demo Importer. Choose your industry demo and click Import. Takes 1–2 minutes on a fresh installation.

4

Choose Your Skin

Go to Appearance → Customize → Skin Settings. Choose from 20 included skins. Each skin is a complete design system with colors, fonts, and component styles.

5

Start Building

Edit any page with Elementor. All 80+ ThemeFlex widgets appear under the "ThemeFlex" category in the Elementor widget panel.

The 16-Token Color System

Every skin defines 16 semantic CSS custom properties. These cascade through every widget automatically:

/* Main scheme */
--sf-bg           Background color
--sf-bg-2         Alternate/card background
--sf-border       Border color
--sf-title        Heading text color
--sf-text         Body text color
--sf-meta         Muted/secondary text
--sf-link         Link color (= primary)
--sf-hover        Hover state color

/* Alt scheme (dark sections, footer) */
--sf-alt-bg       Dark section background
--sf-alt-bg-2     Dark card background
--sf-alt-border   Dark section border

--sf-alt-text     Dark section text
--sf-alt-meta     Dark section muted text

AI Content Assistant

The first WordPress theme with OpenAI integration built directly into Elementor widgets. Generate headlines, copy, meta descriptions and more — without leaving the page editor.

Setup

1

Get an OpenAI API Key

Visit platform.openai.com/api-keys, create an account, and generate a new API key.

2

Add API Key to WordPress

Go to Settings → ThemeFlex → AI Settings (or use WP-CLI: wp option update sf_openai_api_key "sk-...")

3

Use the Widget

Add the "AI Content Assistant" widget in Elementor. Choose Quick Prompts or type your own. Click Generate.

Available Models

  • GPT-4o Mini — Fast and cost-effective. Best for short content (headlines, taglines, CTAs)
  • GPT-4o — Most capable. Best for longer content requiring nuance
  • GPT-3.5 Turbo — Legacy. Cheapest but lower quality

Custom System Prompts

Each widget instance has its own system prompt. Customize it to match your brand voice:

// Example: E-commerce brand

White Label

Rebrand ThemeFlex Addons for client sites. Replace plugin name, author, support URL, and hide the plugin from the plugins list entirely.

Enabling White Label

Go to Settings → White Label in wp-admin. Enable white labeling and fill in your agency details.

Options

Plugin Name

Replace "ThemeFlex Addons" with your agency name, e.g. "Acme Agency Toolkit"

Author Name & URL

Replace "WhatsDigital" with your agency name and website in the plugins list

Support URL

Point "Plugin URI" and "Author URI" links to your own support page

Hide from Plugin List

Make the plugin completely invisible to clients in the WordPress plugins list. They won't know what's powering their site.

Custom Admin CSS

Inject custom CSS into wp-admin for branding (logo replacement, color changes, etc.)

Via Code (wp-config.php)

// Alternatively, set via option in wp-config.php
add_filter('pre_option_sfa_white_label', function() {
    return [
        'enabled'     => true,
        'plugin_name' => 'My Agency Tools',
        'author_name' => 'My Agency',
        'author_url'  => 'https://myagency.com',
        'hide_from_plugins' => true,
    ];
});

Frequently Asked Questions

Do I need Elementor Pro?

No. All 80+ ThemeFlex widgets work with the free version of Elementor. Elementor Pro adds its own widgets on top — those are optional extras.

Can I use the theme on multiple sites?

A Regular License (ThemeForest) covers one end product used by one client. An Extended License is needed for multiple sites or SaaS applications. Check the Envato license terms for details.

How do I update the theme?

Download the latest version from ThemeForest → Downloads. Upload via Appearance → Themes → Add New → Upload. Your customizations in the Customizer and page content are preserved.

Is the AI Content Assistant free to use?

The widget is included with the theme — you only pay OpenAI's API usage fees (typically $0.001–0.02 per request with GPT-4o Mini). Very affordable for typical usage.

What happens if I deactivate ThemeFlex Addons?

The custom widgets won't render in the frontend, but your content is safe. Reactivating the plugin restores all functionality. Always keep the plugin active on live sites.

Can I create my own custom skin?

Yes! Create a folder in wp-content/themes/themeflex/skins/my-skin/ with skin.json and skin.css. See the existing skins for the required format.
